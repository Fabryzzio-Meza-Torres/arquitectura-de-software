# Key product concepts

| Concept | Definition |
| --- | --- |
| **RemoteSchooly** | Government initiative described by the case study. |
| **Balbuena EduKanvas** | Platform used by Government Teachers, Rural Teachers and Rural Students. |
| **Two-month package** | Official distribution unit containing curriculum and material for one academic period, organized by course, grade and target classroom. |
| **Package manifest** | Versioned inventory containing the identity and integrity value of every file in a package. |
| **Active version** | Complete package version enabled on a school server after every file passes integrity verification. |
| **Distribution topology** | Lima, cloud, departmental server, school server and school LAN. |
| **Temporary transfer cache** | Chunks or transient copies used to download and resume large files. It is removed only after confirmed synchronization and integrity. |
| **Enrollment** | Relationship among a student, course, grade, classroom and assigned teacher, configured by a trained Rural Teacher. |
| **Learning activity** | Task or announcement created by a Rural Teacher for an assigned classroom. A task may accept submissions and receive grades and feedback. |
| **AI assistant** | Agent available to Government Teachers for creating or improving material under skill selection, model selection and token controls. |
| **Token baseline** | Token consumption recorded for a representative, repeatable content-creation workload before optimization. |

The active package is not temporary cache. It remains available throughout the academic
period. There is no technical-account profile: trained Rural Teachers maintain the academic
configuration for their school.
