# Key product decisions

These decisions constrain the requirements, main flows and future architecture.

## KPD-1 — One complete package governs each two-month academic period

Lima publishes one official package for each period. Schools review it during their planning
week and keep its active version available throughout the period.

## KPD-2 — Classroom access is local-first

Teachers and students read active material from the school server over the LAN. External
internet is not part of the normal classroom access path.

## KPD-3 — Integrity verification precedes activation

A school server activates a new version only after every file matches the package manifest.
No partial package becomes visible as active content.

## KPD-4 — Interrupted large-file transfers resume without replacing usable content

Large files use automatic retry or resume after connectivity loss. The currently active
version remains available until its complete replacement passes verification. This decision
does not create a 100% availability commitment or advanced reliability scope.

## KPD-5 — Temporary cache is removed only after confirmation

Transfer chunks and transient copies remain until synchronization and integrity are
confirmed, then are deleted. The active package is retained for the academic period.

## KPD-6 — Corrections create explicit package versions

A correction creates a new version. It never silently overwrites the version currently used
by a school.

## KPD-7 — AI optimization must preserve educational output

The assistant may reuse context, choose relevant skills, select an enabled model and enforce
configured limits. Optimization passes only if a comparable benchmark shows at least 40%
lower token consumption without omitting required output.

## KPD-8 — Academic access follows role, assignment and enrollment

A Rural Student sees only enrolled courses, personal submissions, grades and feedback. A
Rural Teacher sees assigned classrooms and only the student data needed for teaching.

## KPD-9 — Technical configuration is separate from teaching

A secondary technical account configures courses, classrooms, groups, enrollments and
teacher assignments. Rural Teachers do not perform this administration.

## KPD-10 — Official Ministry grade entry remains external

Balbuena EduKanvas records classroom grades but does not export them or enter them into the
Ministry of Education system. That activity remains manual and outside scope.

## KPD-11 — Student questions remain in the classroom

The platform provides no student forum or student-authored comments. Students may read
teacher feedback, while questions are handled in person.
