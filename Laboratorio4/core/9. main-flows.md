# Main flows

Role labels: **[GT]** Government Teacher, **[RT]** Rural Teacher, **[RS]** Rural Student,
**[TA]** technical account and **[SYS]** Balbuena EduKanvas.

## Flow 1 — Prepare and publish a two-month package

1. **[GT]** signs in and selects the academic period.
2. **[GT]** selects preconfigured courses, grades, classrooms and destinations.
3. **[GT]** uploads material or optionally creates and improves it with the AI assistant.
4. **[SYS]** records token use, enforces configured limits and provides file preview.
5. **[GT]** reviews and publishes an identified version.
6. **[SYS]** creates the package manifest and starts distribution.

**Fallbacks:** an unsupported or invalid file is rejected before publication; reaching a
token limit blocks only further AI generation, not manual upload or publication; a corrected
publication creates a new version.

## Flow 2 — Synchronize Lima with a rural school

1. **[SYS]** transfers the package from Lima through the cloud to a departmental server.
2. **[SYS]** transfers the same identified version to each target school server.
3. **[SYS]** automatically retries or resumes an interrupted large file.
4. **[SYS]** verifies every received file against the package manifest.
5. **[SYS]** atomically activates the new version after all files pass verification.
6. **[SYS]** removes temporary transfer cache and reports destination status.

**Fallbacks:** a missing or corrupt file remains inactive and is retried; the school keeps
serving the previous active version; temporary cache is not deleted before confirmation.

## Flow 3 — Plan and conduct a class

1. **[RT]** signs in during the school's planning week.
2. **[RT]** reviews the complete package for assigned classrooms and the current period.
3. During class, **[RT]** opens the active package from the classroom laptop over the LAN.
4. **[RT]** views, plays, downloads or prints required material.
5. **[RS]** signs in on an assigned XO laptop, with teacher assistance when needed.
6. **[RS]** accesses the same active content filtered by enrollment.

**Fallbacks:** loss of external internet does not interrupt local access; a student outside
the target enrollment is denied; an editable file may be downloaded and opened in a
compatible application.

## Flow 4 — Manage a task and submission

1. **[RT]** creates a task for an assigned classroom with instructions, files and a date.
2. **[RT]** publishes it immediately or schedules publication.
3. **[RS]** reviews the task and attaches a file when digital submission is enabled.
4. **[RT]** reviews the submission, assigns a grade and leaves feedback.
5. **[RS]** views the personal result without receiving a comment or forum control.

**Fallbacks:** an unauthorized classroom or student is denied; an invalid attachment is
rejected with an understandable reason; one student's result is never exposed to another.

## Flow 5 — Record two-month grades

1. **[RT]** opens the assigned classroom roster showing the minimum required student data.
2. **[RT]** records or confirms each student's period grade.
3. **[RS]** views only the personal grade.
4. Official Ministry of Education entry occurs manually outside Balbuena EduKanvas.

**Fallbacks:** **[RT]** cannot access another classroom; **[SYS]** records who changed a grade
and when; no grade export or Ministry integration is offered.

> **Committed architecture Happy Path:** Flow 1, then Flow 2, then Flow 3.
