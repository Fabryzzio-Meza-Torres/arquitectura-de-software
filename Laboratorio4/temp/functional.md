# Original functional-requirement notes — superseded

These translated notes preserve the initial input. The reconciled and authoritative backlog
is [`requirements/functional-requirements.md`](requirements/functional-requirements.md).

## Government Teachers at the central level in Lima

- **RF-G1:** Government Teachers must be able to upload course curriculum and distribute it
  to every region.
- **RF-G2:** Government Teachers must be able to keep course curriculum updated in every
  region.
- **RF-G3:** Government Teachers must be able to publish predefined public courses in the
  system.
- **RF-G5:** Government Teachers must be able to access teacher-profile information.
- **RF-G7:** Government Teachers must be able to create class material with AI assistance.
- **RF-G9:** The system must impose a token limit per day and course for Government Teacher
  AI use.
- **RF-G10:** The system must allow videos to be sent as course material.

## Students

- **RF-E1:** Students must be able to access material for each course from the application.
- **RF-E2:** Students must be able to access predefined Government courses from the
  application.
- **RF-E3:** Students must be able to view all their grades.
- **RF-E4:** Students must be able to view comments on their submissions.

## Rural Teachers

- **RF-R1:** Rural Teachers must be able to download videos for offline playback.
- **RF-R2:** Rural Teachers must be able to review course material.
- **RF-R3:** Rural Teachers must be able to create tasks and announcements for their class.
- **RF-R4:** Rural Teachers must be able to schedule delivery of tasks and announcements.
- **RF-R5:** Rural Teachers must be able to record comments on student submissions.
- **RF-R6:** Rural Teachers must be able to receive system notifications.

## System

- **RF-S1:** The system must use a system prompt that selects and combines skills according
  to the material the teacher needs to create.
- **RF-S2:** The system must automatically select the most appropriate AI model for the
  request type.
- **RF-S3:** The system must support scheduled delivery of files, messages and announcements.
- **RF-S4:** The system must provide participation forums for each course.
- **RF-S5:** The system must support announcements.
- **RF-S6:** The system must accept different material file formats.
