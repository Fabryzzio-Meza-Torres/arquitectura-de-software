1. Los incidentes de los Clientes son registrados al Harness por el área de soporte
2. Si el incidente es sencillo, puede ser solucionado por el Área de soporte, el cual registrará
   el ticket en el Harness como solucionado.
3. Si el incidente es difícil, el Área de soporte puede consultar al Harness por ayuda para resolver
   el incidente, y si el Harness asegura la respuesta, el Área de soporte puede cerrar el ticket.
4. El área de ingeniería puede generar tickets para el Harness.
5. El area de ingenieria puede consultar informacion relevante a Harness para solucionar el problema
6. El área de ingeniería puede recibir tickets derivados del sistema Harness
7. Tanto el area de ingenieria como el de soporte pueden finalizar tickets
8. Si el Harness provee una respuesta equivocada, se puede reabrir el ticket para escalarlo
