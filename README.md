# Arquitectura de Software — Monorepo de laboratorios

Este repositorio es el **monorepo de todos los laboratorios del curso de Arquitectura de Software**. Cada carpeta `LaboratorioN` contiene los entregables, especificaciones, requisitos, prototipos y evidencias correspondientes a ese laboratorio.

## Laboratorios

| Carpeta | Contenido |
| --- | --- |
| `Laboratorio1/` | Entregables del primer laboratorio del curso. |
| `Laboratorio2/` | Caso Lea$e: especificación, requisitos, evaluación y POC funcional. |
| `Laboratorio3/` | Caso SendIT: especificación, requisitos y evaluación. |

La documentación específica de cada caso vive dentro de su respectiva carpeta.
