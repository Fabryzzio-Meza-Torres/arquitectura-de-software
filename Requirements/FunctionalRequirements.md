## 4. Requisitos Funcionales

| ID    | Requisito funcional                                                                                                                               |
| ----- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| RF-01 | El sistema debe permitir registrar, consultar y actualizar los datos clínicos, diagnósticos, tratamientos e indicaciones de cada paciente de UCI. |
| RF-02 | El sistema debe conservar el historial de cambios clínicos indicando el profesional responsable, la fecha y la hora.                              |
| RF-03 | El sistema debe facilitar la entrega de pacientes entre turnos de profesionales para que todos puedan ser atendidos.                              |
| RF-04 | El sistema debe administrar los horarios del personal y detectar turnos sin cobertura, cruces y asignaciones duplicadas.                          |
| RF-05 | El sistema debe permitir registrar, aprobar y comunicar ausencias, reemplazos y cambios de turno.                                                 |
| RF-06 | El sistema debe permitir generar alertas clínicas priorizadas en base al estado crítico de cada paciente para disponibilizar profesionales        |
| RF-07 | El sistema debe escalar automáticamente una alerta cuando el profesional responsable no responda dentro del tiempo establecido.                   |
| RF-08 | El sistema debe controlar las acciones y la información disponible según el rol del usuario.                                                      |
